# SmartLead AI

Fit Society SmartLead AI, spor psikolojisi alanında yapay zekâ destekli müşteri yönetimi ve satış süreçlerini kolaylaştırmak amacıyla geliştirilmiş bir web uygulamasıdır.

## Proje Hakkında

SmartLead AI; müşteri adaylarının yönetilmesini, satış süreçlerinin takip edilmesini ve yapay zekâ destekli öneriler alınmasını sağlayan bir sistemdir.

Proje iki ana arayüzden oluşmaktadır:
- Kullanıcı / müşteri tarafı
- Yönetici / satış tarafı

## Kullanılan Teknolojiler

- Python
- HTML / CSS
- Docker
- SQLite
- Yapay zekâ API entegrasyonu
- Wix

## Çalıştırma

Projeyi çalıştırmak için gerekli Python paketleri:

`pip install -r requirements.txt`

Ardından uygulama Docker veya uygun Python ortamında çalıştırılabilir.

## Canlı Sistem

Frontend: Wix üzerinde yayınlanmıştır.

Backend: Render üzerinde deploy edilmiştir.

## Not

API anahtarları ve `.env` dosyası güvenlik nedeniyle GitHub deposuna eklenmemiştir.
